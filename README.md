# Seesh Shell

**Seesh** is a simple, customizable shell written in C. It aims to provide a lightweight and efficient environment for interacting with the operating system, handling commands, and running processes. It is designed to demonstrate core shell concepts such as command parsing, process handling, and environment variable management.

## Features

- **Command execution**: Seesh can execute basic system commands, and handle user inputs in an interactive terminal.
- **Customizable prompt**: Allows for dynamic changes to the shell prompt, providing a personalized experience.
- **Environment variable support**: Basic support for setting and retrieving environment variables.
- **Background process support**: Seesh supports running processes in the background using the `&` symbol.
- **Simple and extensible**: Easily extendable for adding new features or enhancing functionality.
